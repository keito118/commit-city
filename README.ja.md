# commit-city

**GitHubのリポジトリを3Dの街にして、その歴史を再生する。**

リポジトリを入れると、コードがブラウザの中で街になります。フォルダは区画、ファイルはビルで、大きいファイルほど高いビルになります。街を見て回り、ビルをクリックすると、そのファイルをGitHubで開けます。

![three.js の街](docs/screenshot.png)

> 状態：v0.1。今のリポジトリの姿を街にします。コミット履歴の再生は次の版で入れます（ロードマップ参照）。

## 街の読み方

| 街 | リポジトリ |
|---|---|
| 区画（一段高い台） | フォルダ。深いフォルダほど高い位置にある |
| ビル | ファイル |
| 高さ | ファイルサイズ（対数。巨大なファイル1つで他が見えなくならないように） |
| 敷地の広さ | これもファイルサイズだが、差はずっと小さい。街の印象は高さで決まる |
| 色 | ファイルの種類（JS/TS、Python、ドキュメント、設定など） |

区画の配置には squarified treemap を使い、すべてのビルを1つのインスタンスメッシュで描くので、数万ファイルのリポジトリでも滑らかに動きます。

## 使い方

URLにリポジトリを付けてページを開きます。

```
https://keito118.github.io/commit-city/?repo=vitejs/vite
https://keito118.github.io/commit-city/?repo=mrdoob/three.js&theme=cyberpunk
```

または、入力欄に `owner/repo`（GitHubのURLでも可）を入れます。URLも一緒に変わるので、見ている街をそのまま共有できます。

- ドラッグで回転、右ドラッグで移動、スクロールでズーム
- ビルをクリックすると、パスとサイズ、ファイルへのリンクが出る
- **Theme** で見た目を選べる

使えるのは公開リポジトリだけです。GitHubの認証なしAPIを使うので、1つのIPから1時間に60回までです（街1つで2回使います）。

## テーマ

見た目は配置とは切り離した「着せ替え」です。v0.1 には **Daylight** と **Cyberpunk** があります。テーマは [`src/themes.ts`](src/themes.ts) の1項目で、空、地面、区画の色、ファイルの種類ごとの色、ビルの光り具合を決めます。日本の町並みや西洋の旧市街も追加予定です。

## 手元で動かす

```bash
npm install
npm run dev     # http://localhost:5173/?repo=vitejs/vite
npm test
npm run build   # dist/ に静的サイトを出力
```

TypeScript、[Three.js](https://threejs.org/)、[d3-hierarchy](https://github.com/d3/d3-hierarchy)（treemap）、Vite で作っています。サーバーはなく、すべてブラウザで動きます。
